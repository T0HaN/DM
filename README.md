# D&D Companion - Приложение для проведения настольно-ролевых игр

Веб-приложение для помощи в проведении партий D&D с полным листом персонажа и общим чатом для бросков кубов.

## Функционал

### 1. Лист персонажа
- **Основная информация**: имя, раса, класс, уровень, бонус мастерства (автоматический расчет)
- **Характеристики и Навыки**: 
  - 6 основных характеристик с автоматическим расчетом модификаторов
  - Спасброски с возможностью включения владения
  - Все навыки с проверками владения и временными бонусами
  - Кнопки для быстрых бросков
- **Атаки и Заклинания**:
  - Добавление оружия с настройкой бонуса атаки
  - Несколько типов урона (дробящий, холодом, огненный и т.д.)
  - Автоматические броски атаки и урона в чат
  - Описание эффектов
- **Инвентарь**:
  - Предметы с количеством и весом
  - Отслеживание предметов, требующих настройки (Attunement)
  - Бонусы к КД, спасброскам и навыкам
  - Подсчет общего веса
- **Особенности и Черты**:
  - Расовые и классовые способности
  - Трекер использований с ограниченным ресурсом
  - Восстановление после короткого/долгое отдыха одной кнопкой

### 2. Чат и Броски кубов
- Подключение к комнате для игры с другими игроками
- Все броски видны всем игрокам в комнате
- Умные броски:
  - При броске навыка автоматически учитываются характеристики, владение и бонусы
  - При броске атаки отдельно показывается бросок атаки и бросок урона
  - При броске спасброска учитывается владение
- Быстрые кнопки для бросков d4, d6, d8, d10, d12, d20, d100
- Детальное отображение результатов: каждый кубик, модификаторы, итоговая сумма

## Запуск

### Установка зависимостей
```bash
npm install
```

### Запуск сервера (для мультиплеера)
В одном терминале:
```bash
npm run server
```

### Запуск клиентского приложения
В другом терминале:
```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:5173

## Технологии
- React + Vite (фронтенд)
- Socket.IO (реальное время для чата и бросков)
- Node.js (сервер для синхронизации)
- LocalStorage (сохранение листа персонажа)
